一反身代词 -self / -selves

第一人称第二人称第三人称
单myselfyourselfhimself / herself / itself
复ourselvesyourselvesthemselves

三种用法：① 动词/介词宾语（enjoy oneself）② 同位语表强调（I cooked it myself）③ 表语（Just be yourself.）

常接：cut / hurt / protect / teach / enjoy / help / take care of / look after

五动词不定式 to + 动词原形

三种句法作用：作宾语（want to visit）／作目的状语（ran to get）／作宾语补足语（told me to be careful）

否定式：not + to do —— prefer not to talk about it.

疑问词 + 不定式：what / which / how / where / when + to do（how to use it）

不带 to：感官动词 see / hear / watch / feel / notice ＋ 使役动词 let / make / have

The referee saw Matt push the other player. / Let me know.

二情态动词 should / could

should：应该；应当 —— 表职责义务、提出劝告、主观看法，后接动词原形。

You should wear a mask when you're outside.

否定：should not / shouldn't（不应当）—— You shouldn't eat so much.

could：提建议，比 can 更委婉 —— You could take some fruit or flowers.

六连词 并列 / 从属

并列：and、but、for、or、both ... and ...、not only ... but also ...

从属：when、while、as、before、after、until、if、because、although、though、than、so that、so ... that、unless、as soon as

⚠ 两个不能连用：though / although 不与 but 连用；because 不与 so 连用。

× Although he was busy, but he helped me. → 删 but

三过去进行时 was / were + doing

用法：过去某一时刻或某一段时间正在进行的动作；常与特定过去时间状语连用。

What was Kate doing at the time of the earthquake?
She was doing her homework.

为动作提供背景：Everyone was enjoying the weather. Some people were swimming.

长短对比：持续时间长的用过去进行时，短的一般过去时。

vs 一般过去时：wrote（写完了）／was writing（不一定写完）

七状语从句 七种类型

类型引导连词
时间before / after / when / while / as / as soon as / since / not ... until / whenever
地点where / wherever

让步although / even though

⚠ 时态：时间/条件状语从句中，用一般现在时表将来。If it doesn't rain tomorrow, we'll go for a picnic.

四现在完成时 have / has + 过去分词

四种用法：① 过去动作对现在的影响或结果 ② 从过去持续到现在（since / for）③ 与 already / never / ever / just / before / yet 连用 ④ have been to 去过（已回）／have gone to 去了（未回）

vs 一般过去时：现在完成时不能与 yesterday、last night、three weeks ago、in 1990 等过去时间状语连用。

非延续性动词：一般不与持续时间状语连用；但否定结构中可以。I haven't bought any food since last week.

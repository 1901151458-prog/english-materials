九年级上册语法速查表

一被动语态 be + 过去分词

时态结构例（ask）
一般现在am/is/are + doneis asked
一般过去was/were + donewas asked
一般将来will be + donewill be asked
情态动词modal + be + donemust be asked
现在完成have/has been + donehas been asked
过去完成had been + donehad been asked
现在进行am/is/are being + doneis being asked
不定式to be + doneto be asked

三步转换：宾语提前作主语 → 动词变 be+done → 原主变 by（可省）

注意：happen / take place / break out / belong to 无被动。

It is said / reported / believed / thought / well known that … ＝ 据说 / 据报道 / 人们相信 / 人们认为 / 众所周知

二宾语从句 引导词 + 陈述语序

原句类型引导词例
陈述句that（可省）I think (that) he is right.
一般疑问句if / whetherI wonder if he will come.
特殊疑问句wh- 词Do you know where he lives?

语序：一律「主语 + 谓语」，不倒装。× where does he live → ✓ where he lives

时态：主现从随便；主过从过去；客观真理用现在。

句首「是否」只用 whether：Whether he will come is unknown.（不能用 If）

简化：what I should do → what to do；whether I should go → whether to go（主语一致时）

三关系从句 先行词 + 关系词 + 从句

关系词指代例
that物 / 人music that touches me
which物the song which uses the erhu
who人the man who never gives up

省略：作宾语可省（that/which/who）；作主语不可省。

限制性非限制性
逗号无必须有
关系词that/which/whowhich/who（不用 that）
省略作宾语可省不可省
先行词名词/代词名词/代词/整个主句

指代整句只用 which：He passed the exam, which made his parents happy.

四it 句型 It is + adj. + (for/of sb) + to do

用 for：形容词说「事」用 of：形容词说「人」
important / necessarykind / nice
hard / easy / difficultclever / polite
useful / possiblefoolish / careless

判断：把 sb 提到前面，能说「sb is adj.」→ 用 of；否则用 for。

It is kind of you to help me.（You are kind. ✓）

It is hard for us to finish it.（We are hard. ✗ → for）

同义转换：To learn English well is important. ＝ It is important to learn English well.
